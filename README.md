# نظام إدارة المبيعات والصيانة المتكامل (Modular Management System)

هذا المستودع يحتوي على الواجهة الأمامية (Frontend) لنظام إدارة مخصص لمتاجر بيع الهواتف والإلكترونيات، مصمم بهيكلية تطبيقات مستقلة تشبه نظام (Odoo).

## المميزات الحالية 🌟
- **تصميم Modular:** شاشة رئيسية (Hub) تتيح الوصول لتطبيقات فرعية بشكل مستقل.
- **تطبيقات مدمجة:** واجهات مخصصة لنقطة البيع (POS)، المخازن وتوليد الباركود، الصيانة، وإدارة الأقساط.
- **تجاوب سريع (Responsive):** الواجهة مبنية لتكون متجاوبة بالكامل لتناسب بيئة العمل السريعة للكاشير والفنيين.

## التقنيات المستخدمة 🛠️
- HTML5
- Tailwind CSS (عبر CDN لسهولة الاستخدام والتعديل المباشر).
- Vanilla JavaScript (لإدارة حالة الـ SPA والتنقل السريع بين التطبيقات).

## خطوات التطوير القادمة 🚀
- استبدال الـ Mock Data وتوصيل الواجهة الأمامية بمحركات قواعد البيانات المحلية.
- بناء الجسر المحاسبي (Accounting API Sync) باستخدام C# / ASP.NET.
- دمج رسائل الإشعارات (SMS/WhatsApp) لتطبيق الأقساط.
